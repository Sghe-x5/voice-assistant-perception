# Восприятие умности голосового ассистента

Главный вопрос — как измерять и предсказывать воспринимаемую умность ассистента
по наблюдаемому диалогу. Отдельные эксперименты помогут проверить, почему
определённые свойства взаимодействия меняют оценку. Умность, полезность, доверие
и успешность выполнения задачи измеряем отдельно.

Исследование продолжается. Здесь собраны изученные источники, промежуточные
результаты расчётов и материалы для следующего этапа.

## Что уже изучили и подготовили

- **Разобрали опубликованные данные.** Четыре эксперимента из трёх
  исследований: 553 записи с оценками голосовых видеосценариев, 148 — из текстовой
  совместной работы с ИИ, 240 — из текстового эксперимента с задержками. Это
  разные выборки; складывать их в одну модель восприятия голосового диалога нельзя.
- **Сопоставили возможные объяснения с исследованиями.** Память, исправление
  ошибок, инициатива, усилия пользователя и перенос ожиданий уже изучаются
  в других работах. [Обзор](research/research_questions.md) показывает, что известно
  и какие различия ещё стоит проверить. Существенная новизна нашего подхода
  пока не установлена.
- **Подготовили материалы одного сценарного эксперимента.** Участник читает, как ассистент и отдельный
  модуль решают задачу, затем оценивает ассистента и прогнозирует его успех
  в новых задачах. Форма, сохранение ответов и расчёты реализованы.
- **Инструменты наблюдения за диалогами.** Есть дневник, правила разметки и форма
  для сравнения двух ассистентов. Человеческие данные по этим протоколам ещё не собраны.

В проанализированных данных другие оценки того же человека — например, доверие —
предсказывают оценку умности лучше проверенных простых признаков взаимодействия.
Эта связь не объясняет, что именно вызывает впечатление умности. Следующий этап —
проверить вопросы анкеты и подготовить собственный корпус: диалоги, условия,
результат задачи, независимая разметка и оценки пользователей. Затем сравнить
прогнозные модели и выбрать один эксперимент для проверки объяснения.
Сценарная форма — одна из заготовок; её человеческие результаты ещё не получены.

## Воспроизвести анализ

Нужен Python 3.12. Платные API и ключи не требуются.

```bash
git clone https://github.com/Sghe-x5/voice-assistant-perception.git
cd voice-assistant-perception
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/run_all.py --download
```

Команда загружает исходные файлы, проверяет их хеши, выполняет анализ и тесты,
сохраняет таблицы в `results/`. Для повторного запуска с уже загруженными данными
уберите `--download`: оригиналы будут проверены, а производные CSV созданы заново.

На Windows замените `.venv/bin/python` на `.venv\Scripts\python.exe`.
Полный расчёт проверялся на macOS ARM64; полная совместимость с Windows не проверена.

Для сценарного эксперимента достаточно стандартной библиотеки Python — см.
[его инструкцию](pilot/process_transfer/README.md). Все тесты после установки
зависимостей и подготовки данных:

```bash
.venv/bin/python -m unittest discover -s tests -v
```

`docs/` — инструкции и план.
