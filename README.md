# Voice Assistant Perception

Исследуем, почему ассистент кажется человеку «умным» и какие признаки взаимодействия
помогают предсказать это впечатление. Разделяем **воспринимаемый интеллект**, доверие,
полезность и фактическое выполнение задачи.

**Сейчас:** воспроизводимый вторичный анализ четырёх экспериментов из публикаций
2026 года, 941 запись участников, исследовательская модель и статья.
**Ещё не сделано:** новый живой голосовой эксперимент и подтверждение общей
объяснительной модели. Первенство и универсальная шкала не заявляются.

Ключевой результат: соседние субъективные оценки предсказывают ощущение умности
гораздо лучше проверенных простых признаков взаимодействия. Это результат для
конкретных данных, а не доказательство причинного механизма или бесполезности
более богатых метрик. Голосовой источник содержит оценки видео; остальные два —
реальные текстовые взаимодействия.

## Быстрый старт

Нужен Python **3.12**. Для анализа не нужны платные API и ключи.
Сначала клонируйте приватный репозиторий под аккаунтом с принятым приглашением:

```bash
git clone https://github.com/Sghe-x5/voice-assistant-perception.git
cd voice-assistant-perception
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/run_all.py --download
```

Команда скачает закреплённые источники, проверит SHA256, выполнит анализы и тесты,
соберёт `paper/manuscript.pdf`. Расчёт занимает несколько минут; первоначальная
загрузка зависит от сети. При повторном запуске без загрузки уберите `--download`.

На Windows используйте установленный Python 3.12 и `.venv\Scripts\python.exe`
вместо `.venv/bin/python`. Полный расчёт проверен на macOS ARM64; CI на Linux
проверяет код и лёгкие тесты. Полная Windows-совместимость пока не подтверждена.

Повторный запуск без `--download` проверяет оригиналы и заново создаёт SPSS CSV
из них: изменение старого производного CSV не должно менять результат проверенного запуска.

Новый план предлагает сначала наблюдение и разметку реальных эпизодов, затем
контролируемый тест доступности информации × политики уточнения, после него —
проверку переноса на GPT, Claude, DeepSeek и другие семейства. Этот эксперимент
**ещё не проведён**. Офлайн-планировщик пар не запускает модели и не создаёт оценки:

```bash
.venv/bin/python pilot/plan_comparison.py --models pilot/model_panel.example.json --seed 20261104 --output pilot/local-comparison-plan
```

### Быстрые проверки без исследовательских данных

```bash
.venv/bin/python -m unittest discover -s tests -p test_pilot_analysis.py -v
.venv/bin/python -m unittest discover -s tests -p test_runner.py -v
```

После полного расчёта доступны все тесты и пример прогноза:

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python src/predict_voice.py --input examples/voice_input.json
```

[Карточка модели](models/voice_model_card.json) объясняет входы и ограничения.
Это исследовательский baseline, а не готовая производственная оценка интеллекта.
