# Voice Assistant Perception

Воспроизводимое исследование пользовательского восприятия «умности» ассистента.

**Статус:** вторичный анализ четырёх экспериментов из трёх публикаций 2026 года,
941 запись участников. Голосовой источник — оценки видеосценариев; остальные
два — реальные текстовые взаимодействия. Новый живой голосовой эксперимент ещё
не проведён. Универсальная модель и мировое первенство не доказаны.

[Статья](output/research_paper.pdf) · [Данные и права](data/PROVENANCE.md) ·
[Методы и литература](research/README.md) · [Следующие шаги](TASKS.md)

## Основные результаты

- Перенос между голосовыми экспериментами: дизайн и сообщённые характеристики
  пользователя дают R²≈0,02; сопутствующая credibility — R²≈0,52. Это различие
  доступной информации, а не установленный причинный механизм.
- Простые журнальные и лексические признаки слабо предсказывают оценки в этих
  выборках. Смысловое качество ответов этим не исключается.
- Двухфакторная модель лучше однофакторной, но абсолютное соответствие недостаточно
  для заявления о валидных независимых компонентах.
- Отбор по распознаванию роли меняет оценку эффекта. Опубликованные средние и
  подвыборка воспроизведены; причинная коррекция отбора не заявляется.

## Воспроизведение

Требуется **Python 3.12**. Платные API и ключи не нужны.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/run_all.py --download
```

Загрузчик проверяет SHA256. Запуск восстанавливает данные, считает модели,
запускает тесты и собирает статью. С локальными исходными файлами опустите
`--download`. Сеть нужна только для установки и первоначальной загрузки.
Проверенная среда — Python 3.12, macOS ARM64; полный расчёт на других ОС отдельно
не проверялся.

Независимые проверки после основного запуска (лексическая проверка также входит в полный запуск):

```bash
.venv/bin/python review_stats/check_arithmetic.py
.venv/bin/python review_stats/ordinal_structure.py
.venv/bin/python review_text/analyze_lexical.py
```

## Модель и тесты

```bash
.venv/bin/python src/predict_voice.py --input examples/voice_input.json
.venv/bin/python -m unittest discover -s tests -v
```

[Карточка модели](models/voice_model_card.json) определяет поля и ограничения.
Это исследовательский ridge-baseline по видеосценариям, с небольшой внешней
предсказательной способностью. Индивидуальный интервал не откалиброван.
Полные тесты требуют результатов основного запуска. CI без данных проверяет
синтаксис, обработку сбоев запуска и приём пилотных экспортов, не заменяя научное воспроизведение.

## Пилот

Откройте [локальную форму](pilot/rating_form.html) в браузере.
[Промпты](pilot/prompts_ru.txt), [протокол](pilot/protocol.txt) и
[анализ экспорта](pilot/analysis_readme.txt) находятся рядом. Ключ разметки
открывается после субъективных оценок. Форма ничего не отправляет.
Один человек с несколькими диалогами остаётся одним участником; агентные прогоны
не заменяют человеческие оценки. Экспорты и транскрипты в Git не добавляются.

| Каталог | Назначение |
|---|---|
| `src/` | Основные анализы, bootstrap и предсказание |

| `tests/` | Проверки источников, чисел и пилотного импорта |
| `data/` | Манифест загрузки и происхождение данных |

| `output/` | Актуальная статья |
