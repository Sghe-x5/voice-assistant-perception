`scripts/run_all.py` → `download_data.py` → исходные SAV/XLSX/CSV → отдельные
`src/analyze_voice.py`, `analyze_cocreation.py`, `analyze_latency.py` → производные

Пилот: `rating_form.html` → settings/records → localStorage → JSON export →
`analyze_pilot.analyze` → записи/парные различия → `write_report`.
Новый планировщик использует существующие `tasks.json` и `schedule`, но выдаёт
только **назначения будущих сессий**.

## Найденные проблемы и решения

| Класс | Подтверждённая проблема | Решение / граница |
|---|---|---|
| Бизнес-логика | Форма и анализатор запрещали Claude; существующий тест закреплял отказ | Запрет удалён в обеих точках, тест проверяет приём Claude/GPT/DeepSeek/Gemini/Qwen |
| Сериализация / воспроизведение | Проверенный SAV мог сопровождаться изменённым CSV; offline replay доверял CSV | Производные CSV атомарно пересоздаются после проверки всех исходников, включая `--verify-only`; тест воспроизводит старое поведение |
| Метод | Фиксированный следующий prompt не отвечает на произвольное уточнение модели | Старый пилот обозначен как диагностический; новый эксперимент требует адаптивных ветвей |
| Дизайн | Только одна пара A/B недостаточна для панели семейств | Офлайн-планировщик полного блока пар; A/B локальны, стабильные model_id сохраняются. Автоимпорта и популяционного рейтинга нет |
| Научная новизна | Близкие работы уже изучают repair, redundant clarification, стоимость вопросов и восприятие после уточнения | Добавлены первоисточники и матрица; новое направление помечено как гипотеза, не «первое в мире» |
| Отчётность | Статья могла создавать впечатление, что индивидуальные прогнозы находятся в Git | Уточнено: они воспроизводятся локально и исключены из Git |

## Данные, арифметика и методы

Все девять исходных файлов повторно получены из закреплённых публичных источников;
SHA256 совпали. Полный расчёт выполнил три анализа, сравнение информации,
training/test bootstrap (1 000 draws на направление), lexical baseline, тесты и
сборку статьи. Существующие 16 тестов пилота проходили и до изменений: это не
предотвращало устаревший запрет модели. Новые регрессионные тесты сначала падали.

Независимый арифметический скрипт повторно проверил:

- CFA chi-square из ковариационных матриц: максимальная ошибка около `9.7e-13`;
- коэффициенты/SE/CI эффекта роли: около `6.4e-15`;
- независимое переобучение и прогноз: около `4.5e-16`;
- метрики co-creation по индивидуальным прогнозам: около `3.2e-16`;
- latency HC3 и Holm из исходных данных: около `2.1e-14`.

Ordinal sensitivity также выполнена: проверены 64/128 quadrature nodes,
перестановка переменных и положительная определённость матриц. Это по-прежнему
двухэтапная polychoric/ULS-проверка, **не полноценная ordinal CFA/WLSMV**.

Пересчёт не опроверг основные выводы исходной статьи. Большинство отличий
сохранённых агрегатов — машинная точность. В одном дополнительном Spearman
показателе `E2_to_E1_all_shifted/survey_augmented` различие составляет
`0.0000191390797`; MAE/RMSE/R² этой строки согласуются до машинной точности.
Чувствительность рангов к почти совпадающим прогнозам — гипотеза объяснения,
не доказанный источник различия. Побитовая идентичность всех метрик не заявляется;
основной численный вывод и округлённые таблицы от этого не меняются.

Выводы, которые нельзя усиливать: соседние анкетные оценки не являются
объективными причинными факторами; высокая alpha не доказывает независимость
факторов; слабые счётчики событий не опровергают информативность смысла ответа;
перенос между двумя близкими видеоэкспериментами не равен переносу на живую речь.
Повторная проверка уже существующего скрипта — полезная проверка арифметики, но
не независимая внешняя рецензия всей исследовательской модели.

## Источники и полнота проверки

Вновь открыты URL всех 34 записей исходной библиографии, проверены доступные
названия/метаданные и наиболее важные для нового направления разделы. Это
**не полное построчное чтение всех 34 работ**. При ошибке основного URL использован
поиск по DOI/названию; доступность не равна проверке каждого цитируемого вывода.

- PARADISE, SASSI, Godspeed, Moussawi, PMQ, cross-cultural PMQ, Novikova,
  современные voice/text работы и методологические статьи существуют по
  доступным первичным страницам или оригинальным PDF.
- Для Zhao (2024) повторно найден издательский abstract; основной текст ограничен.
- Для Krämer (2026) полный текст недоступен в этой проверке; метаданные подтверждены,
  прежние подробные заявления не считаются заново проверенными.
- Jarvis Bench не вернул читаемый текст. Его нельзя считать заново проверенным
  полноценным источником; исходная ограниченная отметка доступа сохранена.
- DIAL, VOICE-H, VoiceEQ — отчёты владельцев систем. Не приравниваются к
  независимой академической валидации; численные маркетинговые claims не
  становятся нашими эмпирическими результатами.

Добавлены шесть ближайших первоисточников в библиографию, обновлён раздел
перспективной работы. Из них несколько — препринты; статус явно указан.
Сравнение конкретных дизайнов и дальнейшие поисковые запросы находятся в
[матрице новизны](../research/novelty_matrix_2026-11-04.md).

## Что ещё не сделано

Не проведены новый человеческий эксперимент, интервью, валидация русской шкалы,
симуляция мощности, подтверждение механизма и live API-бенчмарк моделей.
Планировщик не вызывает API. Модельные ответы, оценки участников, результаты
гипотез и уровень новизны не выдуманы. Для сбора нужны реальные участники,
зафиксированные конфигурации, согласованный бюджет и протокол обработки данных.

Практические следующие шаги — в [плане исследования](research_plan_ru.md).

## Финальная проверка изменений

38 автоматических тестов прошли, включая отдельный процесс с ASCII locale и
кириллической конфигурацией: файлы планировщика теперь явно пишутся в UTF-8.
Независимый агент-рецензент не нашёл Critical/Important проблем в коде и дизайне;
его небольшое замечание о кодировке воспроизведено тестом и исправлено. Это
техническое ревью, не внешнее научное рецензирование. В браузере проверен переход
к заданиям с тестовой конфигурацией Claude; 0 диалогов, поля человеческих оценок
в агентном режиме отключены. Проверены компиляция Python, синтаксис JavaScript
и отсутствие необработанных citation placeholders в PDF.
