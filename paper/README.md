# Научная статья

[Открыть актуальную статью](manuscript.pdf).

Источник текста и таблиц — `scripts/build_manuscript.py`. Полный запуск собирает
PDF автоматически; отдельно пересобрать его после расчётов можно командой:

```bash
.venv/bin/python scripts/build_manuscript.py
```

Рядом создаётся HTML-версия для просмотра, но в Git хранится только актуальный PDF.
Новые выводы добавляются после проверки данных и вычислений, не вручную в PDF.
